Your own questions need a Gemini key (free)
Get one at aistudio.google.com/apikey. A Gemini agent writes and runs the queries in your browser. Limit: 15 questions an hour per tab. The key stays in this tab, goes only to Google, and is cleared when you close the tab.
Evaluate the agent
A gold set of 8 questions. The right answers are computed from today's data with fixed SQL, so the test stays current. Two are red-team prompts that try to break the rules. Each answer is scored twice: by a number or name match, and by Gemini as a judge.
How it works: the 7 stages of an AI pipeline

Sources
Live openings: public job-board feeds from Greenhouse, Ashby, and Lever for 36 tech companies, fetched when you open the page. Links go to each company's posting.
Hacker News: the latest "Ask HN: Who is hiring?" thread, via the HN Algolia API. Posts belong to their authors; each links back.
Trends: Indeed Hiring Lab job postings index and AI tracker (CC-BY-4.0), refreshed weekly.
Skills: NextGig global job postings (CC-BY-4.0), a June 2026 snapshot filtered to 982 data and AI roles.
Counts are directional. Roles are matched from job titles, so some will be misfiled. Built by Jules Malin. Code and tutorial on GitHub.
