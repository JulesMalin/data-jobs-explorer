How it works
  1. Your browser pulls the data. The page calls the public job-board APIs from Greenhouse, Ashby, and Lever, the Hacker News search API, and Indeed's files on GitHub. No server sits in between.
  2. A database runs inside the page. DuckDB, compiled to WebAssembly, loads each source as a SQL table the first time a tab needs it.
  3. Ready-made questions are fixed SQL. The sentence above each chart is computed from the result, so it changes when the data does.
  4. Your own questions go to a small AI agent. Gemini gets a description of the tables and one tool, run_sql. It writes a query, the page checks that it only reads data and runs it, and Gemini reads the rows or the error. It can fix the query and try again, up to 4 times, then answers in one sentence. Every query it ran is listed under the answer.
  5. Hosting is free. The app is a handful of static files on a free Hugging Face Space. Your Gemini key stays in your browser tab.
Built with DuckDB-WASM, the Gemini API with function calling, and plain JavaScript (no framework). Code and step-by-step tutorial.
Sources

Hacker News: the latest "Ask HN: Who is hiring?" thread, via the HN Algolia API. Posts belong to their authors; each links back.
Trends: Indeed Hiring Lab job postings index and AI tracker (CC-BY-4.0), refreshed weekly.
Skills: NextGig global job postings (CC-BY-4.0), a June 2026 snapshot filtered to 982 data and AI roles.
